# Структура Генерального штабу Збройних сил України

## Командування та керівництво
- [ ] Головнокомандувач Збройних сил України
- [ ] Керівництво Генерального штабу
      ├─ Начальник Генерального штабу
      ├─ Перший заступник
      ├─ Заступники начальника
      └─ Головний сержант ЗСУ

## Функціональні управління (натівська J-структура)
- [x] J-1 Головне управління персоналу Генерального штабу
- [x] J-2 Розвідувальне управління Генерального штабу
       └─ не плутати з ГУР МО — це окрема агенція розвідки при Міністерстві оборони,
  не структурний елемент Генштабу
- [x] J-3 Головне оперативне управління Генерального штабу
- [x] J-4 Головне управління логістики Генерального штабу
- [x] J-5 Головне управління оборонного та мобілізаційного планування Генерального штабу
- [x] J-6 Головне управління зв'язку та кібербезпеки Генерального штабу
- [x] J-7 Головне управління підготовки Генерального штабу
- [x] J-8 Головне фінансово-економічне управління Генерального штабу
- [x] J-9 Центральне управління цивільно-військового співробітництва Генерального штабу
      └─ інформаційна політика

## Штабні центри та елементи забезпечення
- [x] Військово-музичне управління Збройних сил України
      ├─ Центральний військовий оркестр ЗСУ
      ├─ Оркестри гарнізонів
      └─ Церемоніальні підрозділи
- [x] Головне управління морально-психологічного забезпечення Збройних Сил України
      └─ окреме від J-1; соціально-правовий захист, психологічна підготовка
- [x] Служба документального забезпечення Генерального штабу Збройних Сил України
      └─ діловодство, архів, протокол
- [x] Управління з верифікації Генерального штабу Збройних Сил України
      └─ контроль виконання міжнародних договорів, інспекції, обмін даними
- [x] Центральне управління військової освіти і науки Генерального штабу Збройних Сил України
      └─ наукова діяльність, військова освіта, стандарти підготовки
- [x] 101-ша окрема бригада охорони Генерального Штабу Збройних Сил України
      └─ охорона, безпека, пропускний режим
- [ ] Адміністративно-господарче управління Генерального штабу
      └─ забезпечення роботи апарату ГШ
