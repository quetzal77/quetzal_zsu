# Структура Генерального штабу Збройних сил України

- [ ] Головнокомандувач Збройних сил України
- [ ] Керівництво Генерального штабу
      ├─ Начальник Генерального штабу
      ├─ Перший заступник
      ├─ Заступники начальника
      └─ Головний сержант ЗСУ

#### Функціональні управління (натівська J‑структура)
- [ ] Головне управління персоналу J-1 — ✔ висока
- [ ] Розвідувальне управління Генерального штабу J-2 — ⚠ середня
  └─ не плутати з ГУР МО — це окрема агенція розвідки при Міністерстві оборони,
  не структурний елемент Генштабу
- [ ] Головне оперативне управління J-3 — ✔ висока
- [ ] Головне управління логістики J-4 — ✔ висока
- [ ] Головне управління оборонного та мобілізаційного планування J-5 — ✔ висока
- [ ] Головне управління зв'язку та кібербезпеки J-6 — ⚠ середня
  └─ можлива зміна назви з "...та інформаційних систем" на "...та кібербезпеки" —
  потребує підтвердження на актуальну дату
- [ ] Головне управління підготовки J-7 — ✔ висока
- [ ] Головне фінансово-економічне управління J-8 — ✔ висока
- [ ] Головне управління цивільно‑військової взаємодії J-9 — ✔ висока
  └─ інформаційна політика

#### Штабні центри та елементи забезпечення
- [ ] Служба документального забезпечення
      └─ діловодство, архів, протокол
- [ ] Адміністративно‑господарська служба
      └─ забезпечення роботи апарату ГШ
- [ ] Головне управління морально-психологічного забезпечення ЗСУ — ✔ висока
  └─ окреме від J‑1; соціально-правовий захист, психологічна підготовка
- [ ] Управління з верифікації
      └─ контроль виконання міжнародних договорів, інспекції, обмін даними
- [ ] Центральне управління військової освіти і науки Генерального штабу — ✔ висока
      └─ наукова діяльність, військова освіта, стандарти підготовки
- [x] Військово‑музичне управління Генерального штабу
      ├─ Центральний військовий оркестр ЗСУ
      ├─ Оркестри гарнізонів
      └─ Церемоніальні підрозділи
- [x] 101‑ша окрема бригада охорони Генерального штабу
      └─ охорона, безпека, пропускний режим
