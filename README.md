# Портал з'єднань ЗСУ

Довідковий сайт про структуру, з'єднання, битви, спорядження й традиції Збройних Сил України.
Термін «з'єднання» (а не «бригада») навмисний: портал показує не лише бригади, а й полки,
батальйони й окремі команди, а також загальну структуру ЗСУ — види, роди військ і сил,
спецслужби — яку одними бригадами не описати.

Дані зберігаються в SQLite (`data/quetzal_zsu.db`), рендеринг сторінок — на сервері (FastAPI + Jinja2),
без збірки фронтенду.

## Функціонал

- Сторінка структури ЗСУ (`/zsu`) — види ЗСУ, роди військ і сил, спецслужби; окремі сторінки
  розкриваються по мірі наповнення даними (наразі — Сили спеціальних операцій, Сили безпілотних систем)
- Реєстр з'єднань (`/brigades`) із фільтрами за родом військ, корпусом, територіальним командуванням, типом військ, типом з'єднання і регіоном
- Два режими перегляду: картки і таблиця
- Живий пошук за назвою/номером з'єднання без перезавантаження сторінки
- Нарукавні знаки з'єднань (прозорий PNG, єдиний стандарт 440×520)
- Детальна сторінка з'єднання: бойовий шлях, спорядження, традиції, фотогалерея, статистика
- Форми створення й редагування з'єднань, битв, спорядження й традицій (потрібен вхід — див. "Авторизація" нижче)
- Хронологія битв з переліком з'єднань-учасників і їх ролі
- Сторінка статистики: розподіл за родом військ і ОК, хронологія битв
- Довідники: спорядження, традиції
- Сторінка налаштувань (`/settings`) — керування всіма довідниками (роди військ, армійські
  корпуси, територіальні командування, типи військ, типи з'єднань, типи спорядження, регіони й локації)
- Favicon — жовтий тризуб ЗСУ

## Стек

Python 3.13 · FastAPI · Uvicorn · Jinja2 · SQLite (stdlib `sqlite3`, без ORM)

## Структура проєкту

```
app/
├── main.py            # точка входу FastAPI, сесії, exception-handler для логіну, / → /zsu
├── auth.py            # хешування паролів, require_login dependency
├── database.py        # підключення до data/quetzal_zsu.db
├── templates.py       # спільний Jinja2Templates + cache-busting CSS
├── routers/           # auth, zsu, brigades, battles, equipment, traditions, stats, settings
└── templates/         # Jinja2 HTML-шаблони
static/
├── css/style.css      # всі стилі (без збірки)
└── img/               # нарукавні знаки з'єднань, іконки родів військ/сил, логотипи ЗСУ
data/
├── quetzal_zsu.db     # база даних SQLite
├── schema.sql         # канонічна версійована схема БД
└── backups/           # локальні знімки БД (scripts/backup_db.py), поза git
docs/                  # архітектурний опис, вихідні дані з'єднань
.claude/skills/        # Claude Code скіли для розробки
scripts/backup_db.py   # створює знімок БД у data/backups/
quetzal_zsu.ps1        # Windows-скрипт: run / stop / check / install / backup
create_user.py         # CLI для створення/оновлення пароля редактора
```

Детальніше про архітектуру і технічні рішення — у [`CLAUDE.md`](CLAUDE.md) та [`docs/architecture.md`](docs/architecture.md).

## Запуск

Потрібен лише **Python 3.12+**.

### Windows — через `quetzal_zsu.ps1`

Скрипт перевіряє Python, встановлює залежності, запускає сервер. Якщо налаштовано псевдонім у `$PROFILE`:

```powershell
quetzal_zsu run     # запустити
quetzal_zsu stop    # зупинити
quetzal_zsu check   # перевірка без запуску
```

Або напряму:
```powershell
powershell -ExecutionPolicy Bypass -File .\quetzal_zsu.ps1 run
```

Відкрити: http://127.0.0.1:8000/ (редіректить на `/zsu`)

### Будь-яка ОС — вручну

```bash
git clone <URL>
cd quetzal_zsu

python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate

pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

Відкрити: http://127.0.0.1:8000/ · Зупинити: `Ctrl+C`

> Якщо `uvicorn` не знаходиться в PATH — завжди використовуй `python -m uvicorn ...`

### Docker

```bash
docker build -t quetzal-zsu .
docker run --rm -p 8000:8000 -v "$(pwd)/data:/srv/data" quetzal-zsu
```

## Дані

`data/quetzal_zsu.db` містить повні довідники (роди військ, корпуси, регіони, типи з'єднань тощо)
та з'єднання ДШВ, ССО, Сил безпілотних систем і морської піхоти з нарукавними знаками.
Схема версіонується в `data/schema.sql`.

Для імпорту з'єднань з `docs/brigades.md` (Claude Code): `/add-brigades <назва розділу>`
Для додавання нарукавного знака (Claude Code): `/add-brigade-emblem`

### Бекап бази даних

`scripts/backup_db.py` робить знімок БД через `sqlite3.Connection.backup()` (безпечно навіть якщо
сервер працює одночасно) і кладе його в `data/backups/` з таймстампом; лишає автоматично тільки
останні 30 знімків. Ця тека не в git — головна `data/quetzal_zsu.db` і далі версіонується комітами,
а `data/backups/` — швидка локальна страхувальна сітка на випадок невдалого імпорту чи ручної правки.

Windows:
```powershell
quetzal_zsu backup "перед імпортом 28 дивізії"
```

Будь-яка ОС:
```bash
python scripts/backup_db.py "перед імпортом 28 дивізії"
```

Нотатка необов'язкова. Варто робити бекап перед великими змінами (`/add-brigades`, ручні SQL-правки,
зміна схеми) і періодично після сесії дрібних правок через UI.

## Авторизація

Перегляд сайту відкритий для всіх. Створення, редагування й видалення з'єднань, битв,
спорядження, традицій і довідників (сторінка `/settings`) вимагає входу.

Створити (або оновити пароль) редактора:
```bash
python create_user.py <username>
```

Для продакшн-розгортання обов'язково задайте свій `SESSION_SECRET` (інакше буде використано
небезпечний дефолт з попередженням у консолі):
```bash
export SESSION_SECRET="<довгий випадковий рядок>"
```
